# RingSketch 同内存精度实验

当前实验在相同计数器数组分配内存下，比较原版 RingSketch 与优化版。两版均使用 C++ 和同步单线程 AVX2 时钟维护；本轮仅测精度，不测吞吐率。

使用完整 CAIDA 数据流（27,121,713 包），以每条 21 字节记录中的 13 字节五元组作为 item ID，每包推进一个时间单位。窗口为 8192 包，每 10 包先查后插，从窗口内的数据包出现记录中抽样，真值为该 ID 距最近一次出现的时间。四个固定查询种子 131–134 为两种方法提供相同查询及真值，每个内存点共 10,848,684 条配对查询。

| 参数 | 原版 RingSketch | 优化版 RingSketch |
| --- | --- | --- |
| 计数器位宽 | 16-bit | 实际打包的 12-bit |
| 哈希分区数 d | 4 | 5 |
| 哈希种子 | 100–103 | 100–104 |
| 时钟维护 | 单指针 | 快慢双指针 |
| 单／快指针每包推进量 | floor(65535 × 自身总桶数 / 8192) | 同公式 |
| 慢指针每包推进量 | — | 自身总桶数 / 4 |
| 分段阈值／快阶段预算 | — | 1984 / 2111 |
| eg.96 KB 时总桶数／每分区桶数 | 48,000 / 12,000 | 64,000 / 12,800 |

内存预算为 **32–128 KB，步长 8 KB，共 13 点**（1 KB = 1000 B）。设预算为 B 字节，原版总桶数为 B/2，优化版为 20 × floor(B/30)，满足五等分与慢周期 4 的约束。两版计数器数组实际分配均为 B 字节，包含打包对齐和尾部填充；对象开销、输入数据、真值与诊断状态不计入预算。优化版总桶数约增加 33.3%，每分区桶数约增加 6.7%。

统计整个数据流的总体、年轻记录（年龄 1–256）和陈旧记录（257–8192）的 AAE 与 ARE，分别为绝对误差和相对误差的均值，越低越好；AAE 的单位为包时间，ARE 无量纲。图中取四个查询种子的均值，误差棒为样本标准差。CSV 另保留年龄细分、存活桶数、精确命中率及 development/outside_development 辅助分组。
