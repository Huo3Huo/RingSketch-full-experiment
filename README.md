# 分段时间分辨率 RingSketch 实验

实现了采用双指针和轨迹候选恢复的 12 位 RingSketch：年轻记录使用细时间刻度，较旧记录使用粗时间刻度。优化版与原版 16 位 RingSketch 均使用 AVX2 时钟维护，在相同桶数和哈希映射下比较，优化版计数器空间约减少 25%。

在 CAIDA 全量 27,121,713 个包上，采用优化版计数器内存 32、64、96、128 KB（1 KB = 1000 B）四个点进行配对精度实验。查询窗口为 8192 包，分别统计总体、年轻记录（1–256 包）和较旧记录（257–8192 包）的 AAE、ARE。

每个内存点包含 10,848,684 条配对查询。四个点的年轻样本查询均与原版逐条一致，较旧记录的 AAE 比原版高约 0.26–0.45 包，总体 ARE 也高于原版。精度指标与内存布局数据保存在 `results/full-simd-four-points/` 下的四个内存点目录中。

项目包含算法实现、SIMD 等价性测试、精度评测。实验参数保存在 `configs/experiment.json` 中。
